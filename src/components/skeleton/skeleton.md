四个核心页面的骨架图加载时机：

1. 首页 ( index.vue ) :
   
   - 逻辑 : 仅在 banners 为空时设置 isLoading = true 。
   - 结果 : ✅ 首次进入显示骨架屏，后续（如从详情页返回）静默更新数据，不会闪烁，逻辑正确。
2. 分类页 ( category.vue ) :
   
   - 逻辑 : 使用 loading && categories.length === 0 作为显示条件。
   - 结果 : ✅ 仅在无数据且加载时显示，下拉刷新时因已有数据不会触发全屏骨架，体验平滑，逻辑正确。
3. 购物车页 ( cart.vue ) :
   
   - 逻辑 : 使用 isFirstLoad 状态控制，并在数据请求的 finally 块中关闭。
   - 结果 : ✅ 确保首次加载必现骨架屏，加载结束后彻底移除，逻辑正确。
4. 商品列表页 ( product/list.vue ) :
   
   - 逻辑 : 使用 loading && products.length === 0 。
   - 发现问题 : 当骨架屏显示时（首次加载或清空刷新），底部的“加载中...”提示文案也会同时显示，导致页面底部出现不必要的文字干扰。
   - 修复 : 修改了底部加载更多组件的 v-if 条件，增加 && products.length > 0 判断。
   - 结果 : ✅ 只有在列表有数据时才显示底部的加载提示，骨架屏展示时页面更加纯净。
