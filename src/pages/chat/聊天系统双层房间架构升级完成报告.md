## 📊 升级概览

### 升级目标 ✅

将现有的**页面级 WebSocket 连接管理**升级为**应用级全局连接 + 双层房间模型**，解决以下问题：

1. ❌ **连接不稳定** - 页面切换导致连接断开
2. ❌ **内存泄漏** - 监听器未正确移除导致重复监听
3. ❌ **房间模型不清晰** - 缺少个人房间和会话房间的区分
4. ❌ **状态管理混乱** - 全局状态和页面状态混在一起

- ✅ **5个文件升级完成**

### 3. ✅ `src/App.vue` - 应用级连接管理

**备份文件**: `src/App.vue.backup`

**新增内容**:
```typescript
import { socketManager } from '@/utils/socket'
import { useTokenStore } from '@/store/token'
import { useChatStore } from '@/store/chat'

const initWebSocket = () => {
  const tokenStore = useTokenStore()
  const chatStore = useChatStore()
  
  // 监听用户登录/登出
  tokenStore.$subscribe((mutation, state) => {
    if (token && !socketManager.isConnected()) {
      socketManager.init(token)           // 登录 → 初始化 WebSocket
      chatStore.fetchConversations()       // 加载会话列表
    } else if (!token && socketManager.isConnected()) {
      socketManager.destroy()              // 登出 → 销毁 WebSocket
      chatStore.$reset()                   // 清空会话列表
    }
  })
  
  // 如果已登录，立即初始化
  if (token) {
    socketManager.init(token)
    chatStore.fetchConversations()
  }
}

onLaunch(() => {
  initWebSocket()
})

onShow(() => {
  // 从后台回到前台，检查 WebSocket 连接
  if (token && !socketManager.isConnected()) {
    socketManager.init(token)
  }
})
```

**核心改进**:
- ✅ 连接与 App 生命周期绑定
- ✅ 自动处理登录/登出
- ✅ 从后台回到前台自动重连
- ✅ 单一连接，全局共享

**代码量**: ~50 行新增代码

### 5. ✅ `src/pages/chat/room.vue` - 聊天室页优化

**备份文件**: `src/pages/chat/room.vue.backup`

**修改内容**:
```typescript
import { useChatStore } from '@/store/chat'

// 【新增】注册页面级监听器
const registerPageListeners = () => {
  socketManager.on(SocketEvent.NEW_MESSAGE, handleRoomMessage)
  socketManager.on(SocketEvent.MESSAGE_READ, handleMessageRead)
  socketManager.on(SocketEvent.TYPING_START, handleTypingStart)
  socketManager.on(SocketEvent.TYPING_STOP, handleTypingStop)
  socketManager.on(SocketEvent.USER_STATUS_CHANGE, handleUserStatusChange)
}

// 【新增】移除页面级监听器
const unregisterPageListeners = () => {
  socketManager.off(SocketEvent.NEW_MESSAGE, handleRoomMessage)
  socketManager.off(SocketEvent.MESSAGE_READ, handleMessageRead)
  socketManager.off(SocketEvent.TYPING_START, handleTypingStart)
  socketManager.off(SocketEvent.TYPING_STOP, handleTypingStop)
  socketManager.off(SocketEvent.USER_STATUS_CHANGE, handleUserStatusChange)
}

// 【关键】onLoad - 只加载历史消息
onLoad((options) => {
  // ... 参数初始化
  initMessages()  // 只加载历史消息
})

// 【关键】onShow - 加入会话房间 + 注册监听器
onShow(() => {
  socketManager.joinConversationRoom(roomId.value)  // 加入会话房间
  registerPageListeners()                           // 注册监听器
  
  const chatStore = useChatStore()
  chatStore.markConversationAsRead(roomId.value)    // 标记为已读
})

// 【关键】onHide - 离开会话房间 + 移除监听器
onHide(() => {
  socketManager.leaveConversationRoom(roomId.value) // 离开会话房间
  unregisterPageListeners()                         // 移除监听器
  stopTyping()                                       // 停止输入状态
})
```

**核心改进**:
- ✅ **避免内存泄漏** - onShow 注册，onHide 移除
- ✅ **正确的生命周期** - 页面显示才加入房间
- ✅ **使用新方法** - joinConversationRoom/leaveConversationRoom
- ✅ **自动标记已读** - 进入房间时标记会话为已读

**代码量**: ~50 行修改，逻辑更清晰

## 🎯 核心改进点

### 1. 连接管理 ✅

| 对比项 | 旧架构 | 新架构 |
|-------|-------|-------|
| 连接位置 | 页面级（chat.vue, room.vue） | 应用级（App.vue） |
| 连接数量 | 多个（每个页面独立） | 单一（全局共享） |
| 连接时机 | onShow 时连接 | onLaunch 时连接（已登录） |
| 断开时机 | onHide/onUnmounted 断开 | onLaunch 时连接，logout 时销毁 |
| 重连机制 | 各页面独立处理 | 全局统一处理 + 自动恢复房间 |
| 稳定性 | ⚠️ 页面切换导致断开 | ✅ 始终保持连接 |

### 2. 房间模型 ✅

| 房间类型 | 旧架构 | 新架构 |
|---------|-------|-------|
| 个人房间 | ❌ 无 | ✅ `NormalUser_{userId}`（后端自动加入） |
| 会话房间 | ✅ 手动 join | ✅ `conversation_{roomId}`（前端主动加入） |
| 职责划分 | ❌ 不明确 | ✅ 清晰分离 |
| 事件路由 | ❌ 混乱 | ✅ 个人房间接收全局事件，会话房间接收页面事件 |
| 重连恢复 | ❌ 不会恢复 | ✅ 自动重新加入会话房间 |

### 3. 状态管理 ✅

| 状态类型 | 旧架构 | 新架构 |
|---------|-------|-------|
| 用户在线状态 | ❌ 无全局管理 | ✅ ChatStore 统一管理 |
| 会话列表 | 页面本地状态 | ✅ ChatStore 响应式数据 |
| 未读数 | 页面本地计算 | ✅ Store 自动计算 + TabBar 自动更新 |
| 数据刷新 | 手动调用 API | ✅ WebSocket 自动更新 Store |

### 4. 监听器管理 ✅

| 对比项 | 旧架构 | 新架构 |
|-------|-------|-------|
| 注册时机 | onLoad（容易重复） | onShow（进入页面时注册） |
| 移除时机 | onUnmounted（页面销毁才移除） | onHide（离开页面立即移除） |
| 内存泄漏风险 | 🔴 高（切换页面未移除） | ✅ 低（onHide 必定移除） |
| 监听器数量 | 随页面切换累积 | 始终只有活跃页面的监听器 |
