## 功能清单

### ✅ Task 1: Room.vue API 集成
**状态**: 已完成

**实现内容**:
- `loadMessages()`: 分页加载历史消息
  - 支持下拉加载更多
  - 每页加载 50 条消息
  - 自动处理分页状态（has_next, has_prev）
  
- `sendTextMessage()`: 发送文本消息
  - 乐观更新 UI（立即显示消息）
  - 发送成功后替换为服务端返回的消息
  - 失败时标记状态为 failed
  
- `processMessageTime()`: 时间分割线处理
  - 消息间隔超过 5 分钟显示时间分割线
  - 格式化显示：今天/昨天/日期 + 时间

**文件**: `src/pages/chat/room.vue`

### ✅ Task 2: WebSocket 实时消息接收
**状态**: 已完成

**实现内容**:
- `handleRoomMessage()`: 处理新消息事件
  - 过滤当前房间的消息
  - 消息去重（检查 message.id）
  - 自动滚动到最新消息
  - 收到他人消息时播放提示音
  
- `playMessageSound()`: 播放消息提示音
  - 仅在微信小程序端启用
  - 使用 uni.createInnerAudioContext
  
- `initRoomWebSocket()`: 初始化 WebSocket 监听
  - 注册 NEW_MESSAGE 事件
  - 注册 MESSAGE_READ 事件
  - 注册 TYPING_START/STOP 事件
  - 调用 socketManager.joinRoom 加入房间
  
- `cleanupRoomWebSocket()`: 清理 WebSocket 监听
  - 移除所有事件监听器
  - 停止输入状态发送
  - 调用 socketManager.leaveRoom 离开房间

**生命周期集成**:
- `onLoad`: 加载消息 → 初始化 WebSocket → 标记房间已读
- `onShow`: 重新初始化 WebSocket（从后台返回）
- `onHide`: 清理 WebSocket（切换到后台）
- `onUnmounted`: 清理 WebSocket（页面销毁）

**文件**: `src/pages/chat/room.vue`

## 技术架构

### 核心依赖
- **框架**: Vue 3 + Composition API + TypeScript
- **UI 库**: Sard-uniapp (sar-avatar, sar-loading, sar-icon)
- **平台**: uni-app (跨平台小程序框架)
- **实时通信**: Socket.IO Client (WebSocket)
- **状态管理**: ref, computed (Vue 3 响应式 API)

### API 层
- `@/api/chat.ts`:
  - `getMessages(roomId, page, per_page)`: 获取消息历史
  - `sendMessage(roomId, { content, type })`: 发送消息
  - `markRoomAsRead(roomId)`: 标记房间已读

### WebSocket 层
- `@/utils/socket.ts`:
  - `socketManager`: WebSocket 管理单例
  - `on(event, handler)`: 注册事件监听
  - `off(event, handler)`: 移除事件监听
  - `sendTyping(roomId, isTyping)`: 发送输入状态
  - `joinRoom(roomId)` / `leaveRoom(roomId)`: 房间管理

### 事件类型
- `NEW_MESSAGE`: 新消息事件
- `MESSAGE_READ`: 消息已读事件
- `TYPING_START`: 开始输入事件
- `TYPING_STOP`: 停止输入事件

### 2. 消息去重机制
```typescript
const existingMessage = messages.value.some(m => m.id === newMessage.id)
if (existingMessage) {
  console.log('[Room] Duplicate message, ignoring')
  return
}
```

### 3. 时间分割线算法
```typescript
messages.value.forEach((msg, index) => {
  if (index === 0) {
    msg.showTime = true
  } else {
    const prevTime = new Date(messages.value[index - 1].created_at).getTime()
    const currTime = new Date(msg.created_at).getTime()
    msg.showTime = (currTime - prevTime) > 5 * 60 * 1000  // 5 分钟
  }
})
```

### 4. 输入防抖逻辑
```typescript
let typingTimer: number | null = null

const onInputChange = () => {
  if (typingTimer) clearTimeout(typingTimer)
  
  typingTimer = setTimeout(() => {
    startTyping()
  }, 500)  // 500ms 防抖
}
```

### 5. 超时检测
```typescript
const timeoutId = setTimeout(() => {
  if (message.status === 'sending') {
    message.status = 'failed'
    uni.showToast({ title: '发送超时，请重试' })
  }
}, 30000)  // 30 秒超时
```

## 页面生命周期

```
onLoad
  ↓
获取 roomId 和 roomName
  ↓
加载消息历史 (loadMessages)
  ↓
初始化 WebSocket (initRoomWebSocket)
  ↓
标记房间已读 (markRoomAsRead)

---

onShow (从后台返回)
  ↓
重新初始化 WebSocket

---

onHide (切换到后台)
  ↓
清理 WebSocket 监听
  ↓
停止输入状态

---

onUnmounted (页面销毁)
  ↓
清理 WebSocket 监听
```
